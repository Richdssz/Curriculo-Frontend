# Portfólio de Richard Silva

Portfólio pessoal com apresentação, experiências, projetos e contato.

![Página inicial do portfólio](assets/portfolio-home.png)

## Tecnologias

Next.js, React, TypeScript e CSS. A página também consulta dados públicos do GitHub.

## Executar localmente

```bash
npm install
npm run dev
```

Acesse [http://localhost:3067](http://localhost:3067).
